Features

  • The modul works as a Drupal filter of any nodes on it.
  • It makes a table or list of images, videos, documents, compressed or executable files from a directory on the server.
  • When the node is viewed first time the module makes
    • thumbnails from the images,
    • the thumbnails saves into the _tn_ subdirectory,
    • save the datas of files into the database table
    • makes automatically thumbnails and insert into a table of database.
  • It make a slideshow from the images (pictures) of folder

Dependencies

  • Must be installed the GD lib of PHP
  • From Drupal 9.5.1 the jQuery UI is not in the core of Drupal
  • Download and install the contrib modules:
    • jQuery UI: https://www.drupal.org/project/jquery_ui
    • jQuery UI Draggable:https://www.drupal.org/project/jquery_ui_draggable
    • jQuery UI Resizable: https://www.drupal.org/project/jquery_ui_resizable

Installation:

  • Download and install JQuery UI Jquery UI Draggable and jQueríy UI Resizable.
  • Copy the files of module into the modules directory and enable.
  • Set the appropriate properties in the 'admin/config/fz/smplphotoalbum'
  • In the 'admin/config/content/formats' enable the Simple Photoalbum filters in the Full HTML or any other content types
  • Default: The image shown in the other blank window.

Defaults

  • The thumbnails showed in table format (flex)
  • The table has pager
  • The admin sets what kind of files enables / disables. It can
    • image (default),
    • videos (default) normal or HTML5 Video format
    • audio (default) HTML5 Audio format
    • document,
    • compressed,
    • executable,
    • other types
    • prohibited files.
  • The admin can modify the list of extensions of files types

Events

If you click on a thumbnail:

  • image: showing in original size (in colorbox)
  • video: downloads or plays
  • audio: downloads or plays
  • documents, compressed, executable, other types downloaded
  • HTML5 <Audio> and <Video>: plays the media,

Administration settings

  • Maximum width of thumbnail in pixel: number (default: 150px)
  • CSS class of thumbnail: string (default: smpl_image)
  • Root folder of photoalbums: string (default: public://photoalbum/)

All the albums are in a folder structure on the server. This is absolute path in the filesystem. If you use in the path the  __DRUPALROOT__  it substitutes the Drupal path with it.

Using

You can define a content filter on the node if the content filter enabled on the content type.

1. Make a simple photoalbum from a folder - old syntax:

[smpl|/path-to-folder]

2. Make a simple photoalbum from a folder - new syntax: 

[smplphotoalbum]
    {name_of_parameter: value}
[/smplphotoalbum]

{smplphotoalbum}
    {name_of_parameter: value}
{/smplphotoalbum}

Example:

[smplphotoalbum]
	{path: /teszt}
	{number: 12}
	{width: 180px}
[/smplphotoalbum]
	or
{smplphotoalbum}
	{path: /teszt}
	{number: 12}
	{width: 180px}
{/smplphotoalbum}

Parameters:

  • notes: some-text
  • number: number of images on one page (from D8)
  • width: width of thumbnails in pixel
  • order: asc /desc / rand, default asc
  • ascdesc: asc /desc, default asc (D8)
  • sort: sortable of this album - (True/False)
  • sub: is there subtitle (true|false)
  • capt: is there caption (true|false)
  • viewed: shows the number of views
  • voted: shows the number of votes and rank
  • edit: Editable images (true|false)
  • exif: shows the exif onformation of images
  • audio: shows this type of files (true|false)
  • video: shows this type of files (true|false)
  • doc: shows this type of files (true|false)
  • cmp: shows this type of files (true|false)
  • app: shows this type of files (true|false)
  • url: shows the URL of image website
  • target: what is the target (default: _blank)
  • html5: the video and audio file shows with HTML5 audio and video tags
  • autoclose: After save the edited image the edit windows auto close (true|false)
  • upload: Upload enabled filetypes (true|false)
  • Watermark
    • wm: Watermark when show|edit the image (true|false)
    • wmpath: Watermark path
      From public folder (beginning of public://)
      From Simple Photoalbum module default:(beginning of smplphotoalbum://images/).
    • wmalpha: watermark alpha value: 0..100 (in %).
      0 - invisible, 100 - max, default: 10
    • wmcopyright: any text into copyright IPTC/Exif field
    • wmauthor: any text into author / Owner IPTC/Exif field
  • test: test mode, only the true|false
  • method: GET | POST (GET better the testing). Only admin mode!
  • graphicdrv: which graphic driver, gd or imagick (if it installed)
  • lang: hu | en
  • translate: true|false
  • icon: Set the color of icons on the page (_col / _bw)
  • slide: True - Let slideshow. The parameters of slideshow
    • title: - title of slideshow
    • interval: time of changing in sec
    • height: Height of main image (px)
    • style: Mode of changing images - fade / slide / zero / zero1
    • slstyle: string of css settings of the main image. Default: 'max-width: 100%; height: 600px;'

Example:

[smplphotoalbum]
  {title: Bassguitar}
  {path:/2004_Bassguitar}
  {slide: true}
  {interval: 10000}
  {height: 800px}
  {style: fade} 
[/smplphotoalbum]

Edit An image (This is under construction)

If you are administrator you can edit the images online
  • You can edit the name of file, subtitle (caption)
  • Move the image with: mouse drag or keyboard cursor keys
  • Zoom in / out: mouse wheel or keyboard "+" & "-" key
  • You can edit a lot of properties of imagewith buttons and parameters, for example
    • Rotate, flip vertically, horizontally
    • Crop the image
    • Resize the image
    • Make Watermark over the image (Copyright and author info into jpeg file)
    • Make Border and Vignette
    • Normalize, Gamma, Brightness, Saturation, Hue, RGB, Grayscale, Contrast
    • Add Noise, Denoise
    • Sharpen, Emboss, Edge, Blur and Convolution (with convolution matrix)

It is uses the GD driver or Imagick driver if it is installed on server

If the change takes too long you can break it with press the Escape key or push the Cancel button.
