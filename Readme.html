Simple Photoalbum 1.10.x-xxxx ~~~~~~~~~~~~~~~~~~~~~~~~~ Features ~~~~~~~~ - The modul works as a Drupal filter of any nodes on it. - It makes a table / list of images, videos, documents compressed or executable files from a directory on the server. - When the node is viewed pushed the Refresh button the module makes - thumbnails from the images, - the thumbnails saves into the _tn_ subdirectory, - save the datas of files into the database table - makes automatically thumbnails and insert into a table of database. Dependencies ~~~~~~~~~~~~ - Before jQuery UI is in the core of Drupal and there is no dependencies. - From Drupal 9.5.1 the jQuery UI is not in the core of Drupal and download and install the contrib modules from here - jQuery UI: https://www.drupal.org/project/jquery_ui - jQuery UI Draggable:https://www.drupal.org/project/jquery_ui_draggable - jQuery UI Resizable: https://www.drupal.org/project/jquery_ui_resizable Installation: ~~~~~~~~~~~~ - Download and install JQuery UI Jquery UI Draggable and jQuery UI Resizable. - Copy the files of module into the modules directory and enable. - Set the appropriate properties in the admin/config/fz/smplphotoalbum - In the admin/config/content/formats Enable the Simple Photoalbum filters in the Full HTML type. - Default: The image shown in the other blank window. Defaults ~~~~~~~~ - The thumbnails showed in table format (css flex) - The table has pager - The admin sets what kind of files enables / disables. It can - image (enables default), - videos (enables default) normal or HTML5 Video format - audio (enables default) HTML5 Audio format - document, - compressed, - executable, - other types, - prohibited files. - The admin can change the extension of types. Events ~~~~~~ If you click on a thumbnail: - image: showing in original size - Video: downloads or plays - HTML5 Video - plays - audio: downloads or plays - HTML5 Audio - plays - documents, compressed, executable, other types downloads Administration settings ~~~~~~~~~~~~~~~~~~~~~~~ - Maximum number of items on a page - Maximum width of thumbnail: (default 150px) - CSS class of thumbnails (default: smpl_image) - Root folder of photoalbums: This is absolute path in the filesystem. If you use in the path the __DRUPALROOT__ then it substitutes the Drupal path with it. - Rebuild of pathes of menus (for developers) - Shows the URL of associated with items (enable/disable) - Default target of link of image (default: _blank) - Using taxonomy Photoalbum (enable/disable) - Under Construction On the page there are buttons for admin - File upload - upload a file into the folder (if upload enabled) - New Folder - makes a new folder if it is enabled centralized or on this node - Edit Path - Edit subtitles of items of this path - Clear the caches of Drupal and Opcache - Refresh - Refresh or make thumbnails of this path - Play - plays a slideshow from images of this path - Help The admin can enable / disable the - Shows the number of views (downloads) of images (files) - Exif and other properties of images (exif info, bitrate, etc.) and documents - Substitute of item - Link of files (URL of original website etc...) - importance of item - There are buttons below the files and you can - Edit images online (if installed GD or Imagic module on PHP) - Edit the subtitles of images with AI, link, importance, filename of items - Delete from database and directory Simple Photoalbum temporary folder for Editing the images - Change the order of files / images - Using filter in lists (enable / disable) - Check and delete the wrong links from database - Change or delete the subtitles automatically (string substitues with a space) - File types (enable / disable). Let's see on top of this document - Set the lists of extensions of any types Using: ~~~~~ You want to make a simple photoalbum: [smplphotoalbum] {name_of_parameter: value} ... [/smplphotoalbum] {smplphotoalbum} {name_of_parameter: value} ... {/smplphotoalbumn} Parameters ~~~~~~~~~~ title: subtitle: path: notes: some-text number: number of images on one page width: width of thumbnails in pixel lang: en|hu, default: en translate: true|false More parameters ~~~~~~~~~~~~~~~ order: asc /desc / rand, default asc sort: sortable of this album - (true|false) ascdesc: asc /desc, default asc (D8) sub: is there subtitle (true|false) viewed: shows the number of views (true|false) graphicdrv: which graphic driver use to edit? gd or imagick (if it installed) exif: shows the exif onformation of images audio: shows this type of files (true|false) video:shows this type of files (true|false) html5: the video and audio file shows with HTML5 audio and video tags doc:shows this type of files (true|false) cmp:shows this type of files (true|false) app:shows this type of files (true|false) image: shows the images edit: Editable images (true|false) url: shows the URL of image website target: what is the target (default: _blank) autoclose: After save the edited image the edit windows auto close (true|false) ai: using AI for recognition of Images or made by AI upload: can admin upload enabled file types into the photoalbum (true|false) Watermark ~~~~~~~~~ wm: Watermark when show|edit the image (true|false) wmpath: Watermark path From public folder (beginning of public://) From Simple Photoalbum module default:(beginning of smplphotoalbum://images/). wmalpha: watermark alpha value: 0..100 (in %).
0 - invisible, 100 - max, default: 10 wmcopyright: any text into copyright IPTC/Exif field wmauthor: any text into author / Owner IPTC/Exif field Administration/developer parameters ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ test: test mode, only the true|false method: GET / POST icon: Set the color of icons on the page (_col / _bw) Slideshow parameters ~~~~~~~~~~~~~~~~~~~~ slide: True - Let slideshow. The parameters of slideshow title: - title of slideshow interval: time of changin in milisec style: Mode of changing images - fade / slide / zero / zero1 slstyle: string of css settings of the main image. Default: 'max-width: 100%; height: 600px;' Example default ~~~~~~~~~~~~~~~ [smplphotoalbum] {path: /teszt} {number: 12} {width: 180px} [/smplphotoalbum]
Example for slideshow ~~~~~~~~~~~~~~~~~~~~~ [smplphotoalbum] {title: Bassguitar} {path:/2004_Bassguitar} {slide: true} {interval: 10000} {height: 800px} {style: fade} [/smplphotoalbum] Edit An image (this is under construction) ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ If you are administrator you can edit the images online - You can edit the name of file, subtitle (caption) - You can edit a lot of properties of image, for example -- Rotate, flip vertically, horizontally -- Crop the image -- Resize the image -- Make Watermark over the image (Copyright and author info into jpeg file) -- Make Border and Vignette -- Gamma, Brightness, Saturation, Hue, RGB, Grayscale, Contrast -- Add Noise, Denoise -- Sharpen, Emboss, Edge, Blur and Convolution (with convolution matrix) It is uses the GD driver or Imagick driver if it is installed on server If the change takes too long you can break it with press the Escape key or push the Cancel button.
